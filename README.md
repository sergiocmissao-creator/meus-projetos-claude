## Projetos

### `linkedin_growth/`
**LinkedIn Authority Intelligence System** — sistema de inteligência para construção de autoridade
no LinkedIn em cooperativismo, liderança, gestão, estratégia e governança.

Não é um gerador de posts. É um sistema de decisão: o que publicar, onde comentar, quem acompanhar,
quais relacionamentos construir e o que está funcionando de verdade.
